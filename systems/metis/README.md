# Metis design system

A public design reference for the current [Metis website](https://metis.inc/), formerly the Nomic Labs website. Reviewed against the current site and repository at `4bd1a57` (October 21, 2026).

## Design decisions

- Warm white background (`#fafafa`), nearly black ink (`#242220`), and several warm grey text levels.
- Helvetica, regular weight headings, tight tracking, and comfortable body line height.
- Centered hero copy surrounded by pixel shaped media windows.
- Thin frame rules, generous section spacing, and small uppercase labels.
- Dark compact buttons with very modest hover movement.

The portal artwork here is built with CSS gradients and geometric shapes. No original site images, logos, claims, forms, or scripts are included. Start with [`tokens.css`](tokens.css), then copy the component styles from [`components.css`](components.css) and relevant markup from [`index.html`](index.html).
